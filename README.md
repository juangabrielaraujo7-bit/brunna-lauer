# Bruna Lauer — primeira seção

Hero responsiva, construída com HTML, CSS e JavaScript puro a partir da direção visual aprovada. Fundo claro, grafite, marca marrom e detalhes verde-esmeralda. A marca horizontal usa o símbolo arquitetônico e o nome ao lado.

## Executar

Requer Node.js. Sem dependências externas.

```sh
npm run dev
```

Abra http://127.0.0.1:4173. Para gerar os arquivos de publicação, use `npm run build`; saída em `dist/`. Em hospedagem estática também é possível servir a raiz do repositório. Na Vercel: preset Other, build `npm run build`, output `dist`.

## Escopo desta entrega

- Apenas cabeçalho e hero; nenhuma seção de imóveis, depoimentos ou sobre foi inventada.
- Navegação mobile, escolha comprar/alugar, valores específicos por finalidade e filtros acessíveis.
- A busca mostra um resumo dos critérios e oferece contato no perfil oficial do Instagram. Ainda não há catálogo ou integração de pesquisa. Os critérios não são enviados automaticamente ao Instagram.
- Anunciar e Sobre abrem diálogos pequenos com contato. Sem armazenamento de dados pessoais.
- WhatsApp será conectado quando o número oficial for confirmado. Nenhum número foi inventado.
- A foto enviada é mantida como arquivo independente do layout, sem rasterizar texto ou controles. O enquadramento usa camadas da mesma foto para manter o casal visível à direita em desktop.
